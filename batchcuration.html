Full Curation Pass (FCP): Loads all slips and finds families that have no 'phase2' row in pass_progress. RUN sends each family's slips to the API twice; each slip's two verdicts are compared. AGREE-TO-KEEP: no slip changes. AGREE-TO-CHANGE: writes new parent or qualifier to slip. DISAGREE: notes only, into FLAGS.md. When a family finishes (either way), pass_progress row for family is set to pass='phase2' so the next FCP run skips it. To force re-adjudication when: A] empty qualifiers occur: use Broom1; B] slips are edited after (!) adjudication: use Broom2; C] unique problem: delete the family's row from pass_progress. AoA · TC Sweep: Loads every slip and the aoa_norms table (— words), and counts slips whose parent or qualifier is typically learned two or more years later than its child word — only those slips get judged. START sends each such family to the API twice, with the age numbers. Agreement on a CHANGE writes it to the slip; agreement on KEEP writes nothing; disagreement goes to FLAGS. One row per swept family is inserted into pass_progress (pass=tc1) so Start skips it next time. Every written change also appears in the TC Review worklist. All 3 slip changes caused by this sweep (agreed changes, and worklist CONFIRMS and REVERTS) constitute 'edit-after-FCP-adjudication,' so the next Broom2 will pick them up and delete their FCP 'phase2' row, returning them to the docket.
